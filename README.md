# SampleTrack Mobile

Flutter mobile app for LSU and fertilizer sample tracking.

## Setup

1. Install Flutter 3.41 or newer.
2. Copy `.envexample` to `.env`.
3. Set the SampleTrack API base URL and Firebase values.
4. Run `flutter pub get`.

## Run

```bash
flutter run
```

## Verify

```bash
flutter analyze
flutter test
```

Architecture and release guidance: `docs/app-docs.md`.
